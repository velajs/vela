Add optional atomic precomputed write batches with typed results, exact database ownership checks, and conditional audit commands. Drizzle supports native D1 batches and asynchronous SQLite/PostgreSQL transactions. CRUD resources can opt into atomic metadata-only auditing for core mutations; unsupported snapshot, hook, store, and adapter configurations fail before writes. Existing post-commit auditing remains the default.
