'@velajs/cli': minor

**Behavior change:** `vela new` generates a Vite 8 project instead of an SWC precompile. `pnpm dev` runs `vite dev` (Vite's port, 5173), `pnpm build` runs `vite build`, `pnpm preview` serves the build, and `pnpm run deploy` runs `vite build && wrangler deploy`, all through `@cloudflare/vite-plugin`. Vite's Oxc transformer emits the legacy decorators and `design:paramtypes` metadata that constructor injection needs, from options stated once in `oxc.config.ts` and imported by both `vite.config.ts` and `vitest.config.ts`. `wrangler.jsonc` points `main` at `src/worker.ts`, drops the `build` block, and sets no compatibility flags: its compatibility date enables Node.js compatibility, including `node:async_hooks`, by default. The `.swcrc` file, the `@swc/*` dependencies and the lint suppression in `src/app.controller.ts` are gone, and `tsconfig.json` (which keeps `verbatimModuleSyntax` and `isolatedModules`, since Oxc compiles one file at a time) also checks the tests and config files.

Generated projects now include `test/worker.spec.ts`, which `pnpm test` runs inside workerd with `@cloudflare/vitest-plugin`; it calls the Worker's `fetch` handler and reads the body before waiting on the execution context. They pin `@velajs/cli` as a dev dependency, so `pnpm vela route list` works without a separate install, and their `vela.config.ts` imports the decorated `src/` files instead of a `dist/` build. `pnpm typecheck` reads the committed `worker-configuration.d.ts`; `pnpm dev` regenerates it first, and `pnpm types` regenerates it on demand.

**Behavior change:** for a Vite project, one with a `vite.config.*` beside the Wrangler file or the `.wrangler/deploy/config.json` redirect a Vite build writes, `vela deploy check` suggests `CLOUDFLARE_ENV=<env> pnpm build && pnpm exec wrangler deploy --dry-run` as its next step, and its `--json` report adds the build as `nextStep.build` (`{ command, args, env }`). It previously suggested `wrangler deploy --config <file> --env <name> --dry-run`, which bypasses the Vite build and bundles the source with esbuild, without decorator metadata. Other projects keep that suggestion.
