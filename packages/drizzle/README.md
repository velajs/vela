# @velajs/crud-drizzle

[Drizzle ORM](https://orm.drizzle.team) adapter for
[`@velajs/crud`](https://github.com/velajs/crud) — pg, mysql, and sqlite dialects, real
transactions, database-generated ids, and native upsert/bulk/aggregate support.

```bash
pnpm add @velajs/crud @velajs/crud-drizzle drizzle-orm
```
